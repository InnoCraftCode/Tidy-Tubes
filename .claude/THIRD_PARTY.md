# Third-party material in .claude/

The following files are adapted (rewritten for libGDX/Android and this workspace's rules) from
**Claude Code Game Studios**, https://github.com/Donchitos/Claude-Code-Game-Studios, imported
2026-11-05:

- `rules/ui-code.md`, `rules/gameplay-code.md`, `rules/test-standards.md`
- `skills/responsive-ux-review/` (from `ux-review`), `skills/smoke-check/`,
  `skills/bug-report/` (from `bug-report` + `bug-triage`), `skills/playtest-report/`,
  `skills/hotfix/`
- `agents/accessibility-specialist.md`

Not imported on purpose: the Godot/Unity/Unreal specialists, the studio hierarchy (directors,
producer, sprint/epic/story pipeline, director gates) and the bash hooks. They target other
engines or need infrastructure (`production/`, `yaml-helper.sh`) this workspace does not use,
and the workspace's rule is one primary agent per task.
